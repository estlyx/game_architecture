# Один платформер: лекция и семинар

Учебный комплект к лекции 2 курса «Архитектура компьютерных игр».
Одна сцена связывает объяснение архитектуры и работу в настоящем движке Godot.

## С чего начать

1. Распакуйте весь архив в обычную папку на Mac. Не открывайте проект внутри ZIP.
2. Откройте `index.html` в браузере, затем выберите лекцию или инструкцию. `lecture.html` содержит слайды. Это автономные слайды: стрелки переключают, N показывает заметки преподавателя, F включает полный экран. Для заметок лучше использовать отдельное окно или файл `teacher-notes.md`, чтобы не проецировать ответы.
3. Прочитайте `seminar.md`, раздел «До занятия». Установите обычный Godot 4 для macOS, без .NET: https://godotengine.org/download/macos/
4. В менеджере Godot выберите Import и `godot/04_coin/project.godot`. Откройте проект и запустите главную сцену кнопкой ▶ справа сверху. На Mac можно использовать Fn+F5.
5. Управление: A / D или стрелки, пробел для прыжка, R для перезапуска уровня. Сначала нажмите мышью в игровом окне.

## Что внутри

| Файл или папка | Назначение |
| --- | --- |
| index.html | Стартовая страница со ссылками на материалы |
| seminar.html | Читаемая в браузере версия инструкции |
| teacher-notes.html | Заметки преподавателя в браузере |
| student-handout.html | Задание студентам в браузере |
| lecture.html | 19 слайдов для основной лекции, с заметками и временем |
| teacher-notes.md | Подробный ход рассказа и вопросы аудитории |
| seminar.md | Подготовка Mac и пошаговая сборка проекта в редакторе |
| student-handout.md | Задание, критерии и вопросы для сдачи |
| godot/00_room | Только комната и пол |
| godot/01_falling | Герой падает и останавливается на полу |
| godot/02_jump | Движение, прыжок и перезапуск |
| godot/03_platforms | Три платформы как экземпляры одной сцены |
| godot/04_coin | Готовый платформер с монеткой и счётчиком |
| checks/verify_resources.py | Проверка ссылок на ресурсы, состава сцен и параметров прыжка |
| checks/engine-smoke.gd | Дополнительная проверка игры через установленный Godot |

Папки этапов являются отдельными проектами. Они не импортируют друг друга. Для занятия с нуля создайте собственный проект по инструкции. Для репетиции или восстановления импортируйте нужный готовый этап.

## Границы занятия

Рекомендуемый формат: 80 минут лекции и 80 минут семинара. Для семинара на 50 минут откройте готовый этап 04 и выполните только демонстрации из сокращённого сценария. В проекте нет врагов, меню, звука, прокрутки камеры и внешних плагинов. Монетка служит примером связи через сигнал.

Сцены и API подготовлены под Godot 4.x, начиная с 4.3, с рендерером Compatibility и GDScript. Godot 3 не подходит. Точную совместимость с вашей установленной версией нужно проверить репетицией. На момент подготовки Godot не был установлен в доступной среде: ссылки на ресурсы и параметры проекта проверены программно, запуск игры и отображение в редакторе не проверены. Не считайте этот комплект заменой репетиции перед студентами.

## Методическая идея

На каждом шаге: вопрос, прогноз студентов, изменение, наблюдение, объяснение. На слайдах остаётся одна задача. Детали движка вводятся по мере необходимости. Это новый маленький учебный проект, а не копия официальной демоигры Godot и не самостоятельный игровой движок.
