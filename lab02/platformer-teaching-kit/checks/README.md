# Проверка

## Без Godot

Из корня распакованного комплекта:

```sh
python3 checks/verify_resources.py
```

Проверяет ссылки, идентификаторы ресурсов, Input Map, наличие HUD, синтаксис XML SVG и аналитическую достижимость ступенек. Это не парсер GDScript и не проверка поведения игры.

## С установленным Godot

Ниже пример, если Godot.app находится в /Applications. Если приложение лежит в другом месте или называется иначе, измените путь. Сначала перейдите в папку комплекта через cd.

```sh
"/Applications/Godot.app/Contents/MacOS/Godot" --headless --editor --path "$PWD/godot/04_coin" --import --quit
"/Applications/Godot.app/Contents/MacOS/Godot" --headless --path "$PWD/godot/04_coin" --script "$PWD/checks/engine-smoke.gd"
```

После первого импорта остановите headless-редактор, если ваша версия оставляет его открытым. Можно добавить `--quit` к первой команде. Проверка поведения запускает финальную сцену, ожидает приземления, посылает действие движения и прыжка, перемещает героя к монетке и проверяет счёт. Она не проверяет реальную клавиатуру и видимость на проекторе. Для проверки ввода, размеров окна, сигналов при ручном прохождении и экспериментов используйте репетицию из seminar.md.

В доступной среде Godot отсутствовал, поэтому engine-smoke.gd подготовлен, но не запускался. Не помечайте его как пройденный до собственного запуска.
