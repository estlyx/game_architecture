Первый запуск

Установите обычный Godot 4 для macOS с официального сайта. В менеджере проектов выберите Import и файл godot/04_coin/project.godot в распакованном комплекте. Откройте проект и нажмите Run Project. A / D или стрелки: движение. Пробел: прыжок. R: перезапуск.

Начните с репетиции готового этапа 04. Код и ссылки на ресурсы проверены без движка. Запуск в Godot и вид в редакторе ещё нужно проверить на вашем Mac.
