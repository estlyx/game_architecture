# Настройка лабораторной 2

## Подготовка

Установил Godot 4.7.2 без .NET. Распаковал учебный комплект. Проверил движение, прыжок и подбор монетки, ошибок нет.

Команды из корня репозитория:

```sh
brew install --cask godot
unzip ~/Downloads/платформер-учебный-комплект.zip -d lab02
godot --editor --path lab02/platformer-teaching-kit/godot/04_coin
```

В редакторе запускаю игру.

## Проверки

Проверил ресурсы пяти проектов и импорт `02_jump` и `04_coin`. Автоматический тест проверил приземление, движение, прыжок и подбор монетки. Ошибок нет.
