## 2 Карта модулей v0.1

"Танки" - одиночная 2D-игра для macOS. Использую C++ и SDL, движок разрабатываю самостоятельно. Разрешённые зависимости указывают, какие модули можно вызывать.

| Модуль | Ответственность | Публичные операции | Разрешённые зависимости |
| --- | --- | --- | --- |
| Приложение | Запуск, игровой цикл, пауза, перезапуск и выход. Связывает остальные модули. | `run()` - запустить приложение | Ввод, Игра, Столкновения, Отрисовка, Файлы; SDL для времени |
| Ввод | Перевод нажатий в команды движения, выстрела и паузы. | `read_commands()` - получить команды | SDL для событий клавиатуры и окна |
| Игра | Хранение танков, снарядов, здоровья и очков. Поведение противников, урон и исход партии. | `start(level)` - начать партию; `update(commands, dt)` - выполнить шаг; `get_state()` - получить состояние | Столкновения |
| Столкновения | Проверка пересечений. Движение без прохода сквозь препятствия. Правила урона остаются в игре. | `move(body, obstacles)` - переместить тело; `intersects(a, b)` - проверить пересечение | Других модулей не использует |
| Отрисовка | Изображение карты, объектов, здоровья, очков и результата. Получает данные для показа, не меняет игру. | `draw(state)` - показать кадр | SDL для окна и рисования |
| Файлы | Чтение и проверка карты и параметров. Загрузка и сохранение рекорда. | `load_level(path)` - загрузить уровень; `load_record()` и `save_record(score)` - прочитать и записать рекорд | Стандартная библиотека C++ и библиотека JSON |

SDL предоставляет окно, ввод, рисование и время. Цикл, команды, столкновения и загрузку данных реализую в своём движке. Поведение танков, урон и очки задаю в модуле "Игра".

## 3 Архитектурное решение

- Требование: карта и параметры танков меняются через JSON без пересборки (НФТ-5 из ДЗ 1).
- Граница: модуль "Файлы" читает и проверяет JSON. Приложение передаёт готовые данные модулю "Игра", который не обращается к файлам.
- Причина: меняю карту и баланс без изменения игрового кода.
- Цена изменения: при изменении формата обновляю загрузчик и проверяю совместимость существующих карт.
